# Agent Guidelines

## Critical Rules
- **Use Real Data Only**: Always use real, verified data and authoritative sources. Do not make assumptions, invent dummy data, or rely on unverified placeholders across any task or context.
- **Never Use Unicode Long Dashes**: Never use em dashes (U+2014) or en dashes (U+2013) in any file, commit message, code, or documentation. Always use a standard hyphen (-) instead.
