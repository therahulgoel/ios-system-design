# Agent Guidelines

## Critical Rules
- **Use Real Data Only**: Always use real, verified data and authoritative sources. Do not make assumptions, invent dummy data, or rely on unverified placeholders across any task or context.
- **Always Update README.md**: Whenever any specification, architecture document, or guide is added, modified, or updated, always keep `README.md` synchronized and updated across all relevant catalog tables, links, and key concepts.
- **Strictly Hyphen-Only (-)**: Never use em dashes or en dashes across any file or message. Use standard hyphens only.
